CIPA

Cognitive Image Preference Authentication

How It Works

  1. User registers on a secure computer.
  2. User selects one preferred image from 9 images.
  3. The image ID is stored securely.
  4. On an untrusted computer, the same 9 images are shuffled.
  5. User never clicks the secret image.
  6. User only indicates the COLUMN containing it.
  7. After three rounds, the system identifies the image.
