CIPA

Cognitive Image Preference Authentication

Step 1: User registers on a secure computer.
Step 2: User selects one secret image from 9 images.
Step 3: On an untrusted computer, all images are shuffled.
Step 4: User never clicks the secret image directly.
Step 5: Using a 9-card style procedure, the system identifies the secret image.
